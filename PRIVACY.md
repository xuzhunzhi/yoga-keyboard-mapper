# 隐私政策 / Privacy Policy

适用于 Yoga Keyboard Mapper（Microsoft Store 名称：Keyboard Mapper for Yoga Book）。

最后更新：2026-11-08

## 简体中文

**本应用不收集、不存储到别处、也不传输任何个人信息。**

- **不联网**：应用不包含任何网络功能，不会把数据发送给开发者或任何第三方。没有统计、广告或崩溃上报。
- **读取哪些输入**：应用只读取键盘发出的厂商自定义 HID 报告（消费类控制 / 系统控制集合），用来识别特殊键的键码。**不读取、不记录普通按键和输入的文字。**
- **蓝牙扫描**：开启「快速唤醒键盘」后，键盘断开期间应用会做被动蓝牙扫描，只为让 Windows 更快重连键盘。周围设备的广播不会被读取、保存或上传。
- **本地数据**：映射设置保存在本机的 `config.json`，运行日志保存在本机的 `app.log`（只含启动信息、特殊键键码和执行的动作）。这些文件只在你的电脑上，删除即可清除；Microsoft Store 版卸载时会自动删除。
- **开机自启**：仅在你打开开关时启用，可随时在应用内或 Windows「设置 → 应用 → 启动」中关闭。

如有疑问，请在 [GitHub Issues](https://github.com/xuzhunzhi/yoga-keyboard-mapper/issues) 联系。

## English

**This app does not collect, share or transmit any personal information.**

- **No network access**: the app has no network features and sends nothing to the developer or any third party. There is no analytics, advertising or crash reporting.
- **Input it reads**: only the vendor-defined HID reports of the keyboard (consumer control / system control collections), to recognise the code of a special key. **It does not read or record regular keystrokes or typed text.**
- **Bluetooth scanning**: with "Wake the keyboard faster" on, the app runs a passive Bluetooth scan while the keyboard is disconnected, only so Windows reconnects it sooner. Nearby devices' advertisements are not read, stored or uploaded.
- **Local data**: your mappings are stored in `config.json` and a run log in `app.log` (startup information, special-key codes and the actions run), both on your PC only. Delete the files to remove them; uninstalling the Microsoft Store version removes them automatically.
- **Start with Windows**: only when you turn it on; turn it off in the app or in Windows Settings > Apps > Startup.

Questions: [GitHub Issues](https://github.com/xuzhunzhi/yoga-keyboard-mapper/issues).
